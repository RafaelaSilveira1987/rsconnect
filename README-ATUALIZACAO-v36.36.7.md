# RS Connect 36.36.7 — Mobile 0.5.0

Atualização visual do aplicativo mobile. Não há migration nova.

## Aplicação
1. Copie os arquivos do patch sobre a instalação atual 36.36.6.
2. Mantenha a migration `118_contact_origin.sql` aplicada.
3. Confirme que `https://SEU_DOMINIO/mobile-app/ui-0.5.0.css` e `ui-0.5.0.js` respondem HTTP 200.
4. Instale o APK Mobile 0.5.0.

A API e as regras de atendimento permanecem inalteradas.
